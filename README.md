# Sudoku Game & Solver

A complete C++ Sudoku application featuring puzzle generation, backtracking solver, and interactive gameplay. Generates puzzles at Easy, Medium, or Hard difficulty levels.

## 🎮 Features

- **Puzzle Generation**: Random Sudoku puzzles with 3 difficulty levels
- **Backtracking Solver**: Efficient algorithm to solve any valid puzzle
- **Interactive Menu**: User-friendly interface for gameplay
- **Board Display**: Clean 9x9 grid visualization
- **OOP Design**: Clean separation of concerns (Board, Generator, Solver)

## 🛠️ Tech Stack

- **Language**: C++17
- **Build Tools**: CMake or Make
- **Concepts**: OOP, Backtracking, Randomization

## 🚀 Quick Start

### Prerequisites
- C++17 compiler (g++ 7+, Clang 5+, MSVC 2017+)
- CMake (optional) or Make

### Compilation

**Using Make:**
```bash
make
./sudoku
